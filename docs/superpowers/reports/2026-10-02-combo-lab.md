# Trendstyrd kortsiktig handel (2026-10-02)

**Fråga:** ger kortsiktig handel ovanpå trendsignalen från P5 extra daglig vinst? Handeln får bara vara long och bara ske när trenden pekar uppåt.

**Upplägg** (förregistrerad, `entry_research/combo_lab.py`):
- **Data:** Binance 5m, 2025-08 till 2026-09, med verklig funding.
- **Grind:** handel är tillåten under dag D om trendvikten vid stängningen dag D−1 är större än 0.
- **Påbyggnader (overlays),** 1 000 USDT per coin:
  - **Grid:** den grid som bara köper och klarade sig bäst på tickdata.
  - **Scalping:** mål +2 USDT och stopp −4 USDT netto.
  - Båda körs dels på BTC och ETH med deras egen trend som grind, dels på alla 133 coins med BTC-trenden som grind, skalat till två coins kapital.
- **5m-staplar** gynnar griden enligt grid_resolution. Eventuell bias går alltså till påbyggnadernas fördel.

**Resultat** (USDT; H1 = 2025-08 till 02, H2 = 2026-03 till 09):

| | H1 | H2 | Vinstdagar för T + påbyggnad (H1 / H2) |
|---|---|---|---|
| T: trend ensam (1 000 USDT) | −168 | +235 | 37 % / 48 % (T ensam) |
| + grid, egen trend | −200 | +12 | 45 % / 55 % |
| + grid, 133 coins, BTC-trend | −418 | +153 | 40 % / 54 % |
| + scalping, egen trend | −4 632 | −7 115 | 4 % / 4 % |
| + scalping, 133 coins, BTC-trend | −6 130 | −18 413 | 25 % / 8 % |

**Slutsats:**
- **Ingen kombination tillför värde.** Kravet var vinst i båda halvåren och fler vinstdagar än trendstrategin ensam.
- **Grid ovanpå trenden** ger fler vinstdagar men förlorar pengar i H1. Totalt blir den sämre än trenden ensam.
- **Scalping ovanpå trenden** förlorar kraftigt, eftersom avgiften dras på varje affär.

**Noterat om trendstrategin under samma 14 månader:** −168 USDT (−16,8 %) i H1 och +235 USDT i H2. Detta stämmer med P5-resultatet för HOLDOUT-perioden (10/2025–09/2026), där strategin gick svagt plus.
